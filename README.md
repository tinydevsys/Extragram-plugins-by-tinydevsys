# Extragram-plugins-by-tinydevsys

Плагин для [exteraGram](https://exteragram.app/ru) от tinydevsys.

## Плагины

### [Send as Accounts](send_as_accounts/)

Переписка «от других людей»: списки «Отправить от…» дополнены личными
залогиненными аккаунтами (как отправка от канала в группах). В группах
сообщения уходят от выбранного аккаунта, в ЛС и ботах — отправка от
аккаунта с плавающим уведомлением и кнопкой «Переключиться». Долгое
нажатие на аккаунт — полная смена приложения. Статусы «не в чате» /
«исключён» / «забанен», вступление в чат от имени другого аккаунта,
восемь настроек (режимы смены, скрытие, порядок, уведомления,
запоминание отправителя на чат).

- Плагин: [`send_as_accounts/send_as_accounts.py`](send_as_accounts/send_as_accounts.py)
- Документация: [`send_as_accounts/README.md`](send_as_accounts/README.md)
- Иконка: [`send_as_accounts/icon.png`](send_as_accounts/icon.png) (128×128)

## Общие требования

- exteraGram >= 12.5.1
- Plugin SDK >= 1.4.4.3
