# Send as Accounts

Плагин для **exteraGram**, позволяющий писать в чатах «от имени другого
человека» — то есть от своих **личных (залогиненных в приложении) аккаунтов**,
аналогично тому, как уже работает отправка «от имени канала» в группах.

## Что умеет

- **Список «Отправить от…»** (кнопка-аватар в поле ввода / пункт меню чата)
  дополняется личными аккаунтами, залогиненными в exteraGram.
- **Группы**: после выбора аккаунта сообщения в этом чате уходят **от этого
  аккаунта** (отправка идёт через его соединение — как отправка от
  привязанного канала). Аватар отправителя показывается в поле ввода.
- **Личные чаты и боты**: сообщение отправляется от выбранного аккаунта, а
  потом появляется плавающее уведомление «Отправлено от …» с кнопкой
  **«Переключиться»** — приложение переключается на этот аккаунт.
  Альтернативно — немедленная полная смена (настраивается).
- **Долгое нажатие** на аккаунте в списке — полная смена приложения на этот
  аккаунт (независимо от режима, если включено в настройках).
- **Статусы**: аккаунты, которых нет в чате, показаны **серыми** со статусом
  «не в чате»; поддерживаются статусы **«исключён»** (kicked) и
  **«забанен»** (banned). По нажатию на серый аккаунт предлагается
  **вступить в чат** от его имени (если у чата есть публичная ссылка).
- Выбор отправителя можно **запомнить на каждый чат**.

## Как это работает (архитектура)

Telegram-сервер не принимает «send as» для чужих личных аккаунтов
(для `send_as` с `peerUser` сервер вернёт `PEER_INVALID`), поэтому плагин
реализует маршрутизацию на клиенте:

1. Выбранный отправитель хранится как мапа `dialog_id → index аккаунта`
   (в настройках плагина, если включено «Запоминать отправителя»).
2. Хук на `SendMessagesHelper.sendMessage(...)` (оба основных перегруза:
   отправка и пересылка) перехватывает исходящее сообщение и **перенаправляет
   его в `SendMessagesHelper` нужного аккаунта** (вызов через
   `Method.invoke`), отменяя оригинальный вызов. Повторные отправки
   (retry) и секретные чаты не трогает.
3. В группе дополнительно локально ставится `chatFull.default_send_as` на
   `TL_peerUser` выбранного аккаунта, чтобы кнопка-аватар в поле ввода
   выглядела как при отправке от канала.
4. Список «Отправить от…» — попап `SenderSelectPopup`: хук на его конструктор
   подменяет `SelectionAdapter` и обработчики нажатий обёртками, которые
   после оригинальных пунктов (каналов) добавляют ваши аккаунты со статусами.
- В чатах без кнопки «отправить от канала» (обычные группы, ЛС, боты) плагин
  сам показывает такой же попап: перехватывает создание/нажатие кнопки
  `senderSelectView` в `ChatActivityEnterView`.

Ограничения (по природе протокола Telegram):

- **Секретные чаты** — не поддерживаются (секретный чат привязан к одному
  аккаунту, переадресация технически невозможна).
- **Каналы** (ваше собственное администрирование) — отправка от других
  аккаунтов в них невозможна.
- Если аккаунт выбранным отправителем **вылогинился** — плагин позовёт
  об этом, сбросит выбор и отправит от текущего аккаунта.
- Пока в группе выбран другой отправитель, индикатор «печатает…» текущего
  аккаунта в этой группе не виден (побочный эффект `default_send_as`).

## Требования

- exteraGram **>= 12.5.1**
- Plugin SDK **>= 1.4.4.3**
- минимум **два** залогиненных аккаунта в exteraGram (включая текущий)

## Установка

Плагин — одиночный Python-файл (`__id__ = "send_as_accounts"`).
Формат дистрибутива exteraGram — **`.plugin`**: это тот же самый
Python-файл, только переименованный (проверено по публичным плагинам,
например Message-Repeater-Pro и Auto-Forwarder-Plugin).

Вариант 1 — «тапнуть в Telegram» (рекомендуется):

1. Скачать `send_as_accounts.plugin` из репозитория (или переименовать
   `send_as_accounts.py` в `send_as_accounts.plugin` — содержимое
   идентичное).
2. Отправить файл себе в Telegram (например, в «Избранное»).
3. Тапнуть на файл внутри exteraGram — появится диалог
   **INSTALL PLUGIN** — подтвердить.
4. Включить плагин: `Настройки exteraGram → Плагины`.

Вариант 2 — DevServer (разработка): через `adb forward tcp:42690
tcp:42690` отправить команду `write_plugin` с содержимым
`send_as_accounts.py` (порт по умолчанию 42690, см. доки SDK).

После установки файл лежит на устройстве как
`/data/user/0/com.exteragram.messenger/files/plugins/send_as_accounts.py`.

## Настройки

| # | Настройка | По умолчанию | Описание |
|---|-----------|--------------|----------|
| 1 | **Режим смены** | Гибридный | `Переключение отправителя` — группы и ЛС: сообщения идут от аккаунта, в ЛС с предложением переключиться; `Полная смена приложения` — сразу переключает exteraGram на аккаунт, выбор не запоминается; `Гибридный` — группы как «переключение отправителя», ЛС и боты — полная смена |
| 2 | **Долгое нажатие — полная смена** | вкл. | Долгое нажатие на аккаунте в списке полностью переключает приложение на него, независимо от режима |
| 3 | **Скрыть каналы в списке** | выкл. | Показывать в «Отправить от…» только личные аккаунты |
| 4 | **Скрытые аккаунты / Скрытые каналы** | — | Подстраницы: скрыть конкретные аккаунты (переключатели) и конкретные каналы (авто-список замеченных каналов + ввод ID через запятую) |
| 5 | **Порядок аккаунтов** | авто | Подстраница: тап — поднять выше, долгое нажатие — опустить ниже |
| 6 | **Уведомление «отправлено от»** | вкл. | Плавающее уведомление после отправки; в ЛС/ботах — с кнопкой «Переключиться» |
| 7 | **Запоминать отправителя для чата** | вкл. | Сохранять выбор аккаунта для каждого чата (иначе — только до перезапуска приложения) |
| 8 | **Показывать статусы** | вкл. | Статусы «не в чате» / «исключён» / «забанен» в списке аккаунтов |

## Где меню выбора аккаунта

Точки входа (все в меню чата **⋮** в правом верхнем углу):

1. **«Отправлять от…»** — основной пункт, есть в **любом** чате: группы,
   ЛС, боты. Открывает список аккаунтов с статусами.
2. **«Send as Accounts: диагностика»** — состояние плагина: сколько
   аккаунтов видит приложение, зарегистрированы ли хуки, последние события.
3. **Кнопка-аватар в поле ввода** (оригинальная «отправить от канала»):
   - в группах с привязанным каналом список **дополнен вашими аккаунтами**
     (сначала аккаунты, потом каналы);
   - в обычных группах — появляется, если для чата уже выбран отправитель;
   - в **ЛС и ботах** появляется после выбора отправителя (как в группах:
     аватар аккаунта в поле ввода, по тапу — список аккаунтов).

## Использование

1. В чате нажмите **⋮ → «Отправлять от…»** (в группах можно и кнопку-аватар
   в поле ввода).
2. Выберите аккаунт:
   - в **группе** — сообщения начнут уходить от него (аватар в поле ввода
     изменится, серые аккаунты — не в чате);
   - в **ЛС/боте** — в поле ввода появится кнопка-аватар выбранного
     аккаунта (как в группах), при отправке сообщения — уведомление
     «Отправлено от …» с кнопкой «Переключиться».
   - в списке аккаунты идут **сначала**, каналы — после них.
3. Чтобы вернуться к текущему аккаунту — выберите его в списке (помечен
   «текущий») или снимите отправителя, выбрав канал/«текущий».
4. Серый аккаунт + тап — предложение вступить в чат от его имени
   (только для супергрупп с публичной ссылкой).
5. Зажать аккаунт в списке — полная смена приложения на него.

## Диагностика

Если что-то не работает:

1. В списке плагинов (`Настройки exteraGram → Плагины`) плагин должен быть
   **включён**; ошибки загрузки (если есть) показаны красным текстом
   рядом с плагин.
2. В любом чате **⋮ → «Send as Accounts: диагностика»** — диалог покажет:
   версию плагина, число залогиненных аккаунтов, режим, зарегистрированные
   хуки (`4/4` — всё ок), количество запомненных отправителей и последние
   события (включая ошибки с типом и текстом исключения). Полезные строки:
   - `popup ctors: (…) | …` — реальные сигнатуры конструктора окна
     выбора отправителя в вашей версии (плагин подключается к
     подходящему автоматически);
   - `popup hook: ok (ctor)` / `ok (all ctors)` — как подключился хук
     окна (второй вариант — фолбэк, если мост не умеет хукать
     отдельный конструктор);
   - `sender view wrapped` — обработчик клика по кнопке-аватару
     установлен (а также `sender view: …` — если не установлен, с
     причиной);
   - `avatar clicked: dialog=…` — клик по кнопке-аватару дошёл до
     плагина;
   - `own popup opened: dialog=… channels=…` — собственный попап
     открыт (аккаунты + каналы);
   - `inject: popup peer=…` / `accounts injected: N acc + M ch` —
     аккаунты добавлены в окно (при ошибке: `inject error: …`);
   - `popup created: peer=…` — окно (свое или нативное) обработано,
     чат определён, аккаунты добавлены;
   - `createSenderSelectView fired` / `updateSendAsButton fired` —
     живучесть Xposed-хуков (пишутся не чаще раза в минуту).
   - `send: overloads=…` — какие перегрузки `sendMessage` есть в
     установленной версии клиента (плагин сам выбирает нужный путь:
     официальный хук `SendMessageParams` или legacy-Xposed для старых
     сборок);
   - `send redirect -> account N` — факт перенаправления отправки.
   Если после переустановки старая ошибка — сверьте версию в диалоге:
   она должна совпадать с `__version__` файла.
3. Если список аккаунтов пуст — в приложении залогинен только один аккаунт
   (плагину нужно минимум два).

## Иконка

Иконка плагина (синие пузыри с аватаром пользователя и стрелкой отправки):

- `icon.png` — 128×128,
- `icon_source.png` — 1024×1024 (исходник для переупаковки).

Важно: в формате одиночного файла поле `__icon__` принимает только ссылку
на встроенную стикер-пакет хоста (формат `StickerPackShortName/index`,
напр. `exteraPlugins/1`) — встроенный PNG в плагин упаковать нельзя,
поэтому в коде остаётся `__icon__ = "exteraPlugins/1"`. PNG-файлы
предназначены для каталога плагинов / создания собственного стикер-пакета.

## Тестирование

В репозитории есть автономный (десктопный) набор тестов, который прогоняет
логику настоящего `send_as_accounts.py` поверх заглушек exteraGram/Android
(без телефона):

```bash
cd send_as_accounts
python3 tests/test_logic.py
```

157 проверок: метаданные, статусы аккаунтов, порядок/скрытие, мапа
отправителей, три режима смены, редирект отправки — официальный хук
`SendMessageParams` (CANCEL, повторный вход, retry, ЛС с кнопкой
«Переключиться») и legacy-Xposed (27- и 7-арг. перегрузы, boxed-типы,
retry), валидация цели (kicked/banned), инъекция в попап (адаптер, статусы,
делегирование оригинальных пунктов, долгое нажатие, скрытие каналов,
фолбэк `hook_all_constructors`, динамическая сигнатура конструктора,
определение чата из аргументов), собственный попап для ЛС, пункт меню чата,
вступление в чат, настройки, обёртка кнопки-аватара, диагностика.

Файлы:

- `send_as_accounts.py` — плагин (исходник, формат для DevServer/разработки);
- `send_as_accounts.plugin` — тот же файл для установки «тапом в Telegram»;
- `tests/stubs.py` — заглушки экосистемы exteraGram/Java/Android для десктоп-тестов;
- `tests/test_logic.py` — набор тестов (не требуется для установки плагина).
